# Sök

Prakto Akademi har en sökfunktion som täcker allt i din organisation: kurser, lektioner, mappar, communities, diskussioner, lekplatser, poddar och medlemmar. Du kan nå den på tre sätt:

- Knappen **Sök** i toppmenyn, som öppnar [kommandopaletten](/platform/search/keyboard-shortcuts#kommandopaletten).
- Tangentbordet: tryck på <kbd>⌘</kbd> <kbd>K</kbd> (macOS), <kbd>Ctrl</kbd> <kbd>K</kbd> (Windows och Linux) eller <kbd>/</kbd> på valfri sida för elever.
- Den fullständiga söksidan på `/search`, som du också kommer till när du väljer **Se alla resultat** i paletten.

## Det här söks igenom

Varje ord du skriver måste finnas någonstans i resultatet, i valfri ordning och i något av de fält som söks igenom. Det spelar ingen roll om du skriver med stora eller små bokstäver.

| Typ | Fält som söks igenom |
| --- | --- |
| **Kurser** | Namn, beskrivning, om-text, lärandemål, taggar |
| **Lektioner** | Bara lektionens namn (själva innehållet i lektionen söks inte igenom) |
| **Mappar** | Namn, beskrivning |
| **Communities** | Namn, beskrivning |
| **Diskussioner** | Titel, innehåll |
| **Lekplatser** | Namn, beskrivning |
| **Poddar** | Namn, beskrivning, taggar |
| **Medlemmar** | Användarnamn, förnamn, efternamn, presentation |

## Vem ser vad

Sökningen visar aldrig något som du inte skulle kunna öppna från den vanliga listan.

- **Besökare som inte är inloggade** och **inloggade användare som inte är medlemmar** i organisationen ser bara offentligt innehåll. De får aldrig medlemmar i resultaten.
- **Medlemmar** ser också innehåll som bara är öppet för organisationen. Opublicerat innehåll visas aldrig.
- Communities, diskussioner och poddar som är begränsade till användargrupper visas bara för medlemmar i en länkad grupp.
- Lektioner följer kursen de tillhör. En lektion måste vara publicerad och ligga i ett kapitel. Lektioner som är låsta till användargrupper visas bara för organisationens administratörer.
- Resultat för medlemmar visar bara offentliga profiluppgifter (namn, användarnamn, profilbild och presentation). E-postadresser visas aldrig i sökningen.

## Söksidan

Söksidan på `/search` visar resultaten grupperade efter typ, med antalet träffar för varje typ. Använd **Filtrera efter typ** för att begränsa listan till **Alla**, **Kurser**, **Lektioner**, **Mappar**, **Communities**, **Diskussioner**, **Lekplatser**, **Poddar** eller **Medlemmar**. Bläddra mellan sidorna med **Föregående** och **Nästa**.

## Begränsningar

| Begränsning | Värde |
| --- | --- |
| Kortaste sökning | 3 tecken |
| Längsta sökning | 200 tecken |
| Resultat per sida | 10 som standard, högst 50 |
| Antal sökningar (inloggad) | 60 sökningar per minut och användare |
| Antal sökningar (inte inloggad) | 30 sökningar per minut och IP-adress |

Om du söker oftare än så får du vänta en stund innan du kan söka igen.

## Sök i adminpanelen

Adminpanelen har en egen kommandopalett. Tryck på <kbd>⌘</kbd> <kbd>K</kbd> eller <kbd>Ctrl</kbd> <kbd>K</kbd> i adminpanelen för att hoppa till sidor i adminpanelen (kurser, användare, roller, inställningar och så vidare) eller för att söka efter kurser, användare, communities, diskussioner, lekplatser och poddar.
