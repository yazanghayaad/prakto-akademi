# Kommandopaletten och kortkommandon

Du kan röra dig i Prakto Akademi utan mus. Kommandopaletten söker och hoppar till sidor, och kortkommandon med en tangent sköter de vanligaste åtgärderna på varje sida.

Tryck på <kbd>?</kbd> på valfri sida för elever för att öppna listan **Tangentbordsgenvägar**. Den visar alla kortkommandon som fungerar på sidan du är på, grupperade som **Överallt**, **Gå till** och **På den här sidan**.

<Callout type="info">
Kortkommandon fungerar inte medan du skriver i ett textfält, en rullgardinsmeny eller redigeraren. Kortkommandon med <kbd>⌘</kbd>, <kbd>Ctrl</kbd> eller <kbd>Alt</kbd> lämnas åt webbläsaren, förutom kortkommandot för paletten.
</Callout>

## Kommandopaletten

Öppna paletten med <kbd>⌘</kbd> <kbd>K</kbd> på macOS, <kbd>Ctrl</kbd> <kbd>K</kbd> på Windows och Linux, eller <kbd>/</kbd>. Du kan också klicka på **Sök** i toppmenyn.

Innan du börjar skriva visar paletten:

- **Åtgärder**: kortkommandona som finns på den aktuella sidan (till exempel **Starta kursen** på en kurssida).
- **Gå till**: sidorna i din organisation, som Hem, Kurser, Bibliotek, Poddar, Communities, Lekplatser, Framsteg, Tavlor och dina kontosidor. En sida visas bara när funktionen är påslagen för organisationen och du har behörighet att öppna den.

<img src="/docs/img/pages/search/search-palette.webp" alt="Kommandopaletten med sökresultat grupperade efter typ och navigeringstangenterna längst ned" width={1600} height={900} style={{ borderRadius: 10 }} />

Skriv minst 3 tecken för att söka i innehållet. Resultaten grupperas som **Kurser**, **Lektioner**, **Mappar**, **Communities**, **Diskussioner**, **Lekplatser**, **Poddar** och **Medlemmar**, och **Se alla resultat** öppnar den fullständiga [söksidan](/platform/search).

| Tangent | Åtgärd |
| --- | --- |
| <kbd>↑</kbd> <kbd>↓</kbd> | Navigera |
| <kbd>Enter</kbd> | Öppna |
| <kbd>⌘</kbd>/<kbd>Ctrl</kbd> <kbd>Enter</kbd> | Öppna i en ny flik |
| <kbd>Esc</kbd> | Stäng |

## Överallt

| Tangent | Åtgärd |
| --- | --- |
| <kbd>?</kbd> | Öppna listan med kortkommandon |
| <kbd>/</kbd> | Öppna sökningen |
| <kbd>⌘</kbd>/<kbd>Ctrl</kbd> <kbd>K</kbd> | Öppna sökningen |
| <kbd>p</kbd> | Spela upp eller pausa poddspelaren, när den är öppen |

## Gå till

Kortkommandona för "Gå till" är två tangenter som du trycker efter varandra: tryck på <kbd>g</kbd> och sedan på den andra tangenten inom ungefär en sekund.

| Tangenter | Sida |
| --- | --- |
| <kbd>g</kbd> sedan <kbd>h</kbd> | Hem |
| <kbd>g</kbd> sedan <kbd>c</kbd> | Kurser |
| <kbd>g</kbd> sedan <kbd>l</kbd> | Bibliotek |
| <kbd>g</kbd> sedan <kbd>p</kbd> | Poddar |
| <kbd>g</kbd> sedan <kbd>m</kbd> | Communities |
| <kbd>g</kbd> sedan <kbd>y</kbd> | Lekplatser |
| <kbd>g</kbd> sedan <kbd>t</kbd> | Framsteg |
| <kbd>g</kbd> sedan <kbd>b</kbd> | Tavlor |
| <kbd>g</kbd> sedan <kbd>u</kbd> | Kontoinställningar |

En tangentkombination finns bara när sidan är tillgänglig för dig. Om organisationen till exempel har stängt av poddar gör <kbd>g</kbd> <kbd>p</kbd> ingenting.

## Listor och kataloger

De här kortkommandona fungerar på startsidan, i kurskatalogen, i biblioteket och dess mappar, på sidorna för poddar, communities, lekplatser och tavlor, på din sida Framsteg och på söksidan.

| Tangent | Åtgärd |
| --- | --- |
| <kbd>j</kbd> eller <kbd>↓</kbd> | Nästa objekt |
| <kbd>k</kbd> eller <kbd>↑</kbd> | Föregående objekt |
| <kbd>Enter</kbd> | Öppna markerat objekt |
| <kbd>]</kbd> | Nästa sida |
| <kbd>[</kbd> | Föregående sida |

## Kurssida

| Tangent | Åtgärd |
| --- | --- |
| <kbd>s</kbd> | Starta kursen, eller fortsätt där du slutade |
| <kbd>e</kbd> | Expandera eller minimera alla kapitel |

## Lektionssida

| Tangent | Åtgärd |
| --- | --- |
| <kbd>j</kbd> eller <kbd>→</kbd> | Nästa lektion |
| <kbd>k</kbd> eller <kbd>←</kbd> | Föregående lektion |
| <kbd>]</kbd> | Nästa kapitel |
| <kbd>[</kbd> | Föregående kapitel |
| <kbd>m</kbd> | Markera lektionen som slutförd, eller avmarkera den |
| <kbd>f</kbd> | Växla fokusläge |
| <kbd>Esc</kbd> | Avsluta fokusläge |
| <kbd>Space</kbd> | Spela upp eller pausa video |
| <kbd>c</kbd> | Tillbaka till kursen |

I språk som skrivs från höger till vänster är pilarna för nästa och föregående lektion omvända, så att de följer läsriktningen.
