# Block

Skriv `/` var som helst på en sida för att öppna blockmenyn. Börja skriva för att filtrera listan (till exempel `/quiz` eller `/tabell`) och tryck sedan på Enter. Menyn delar in blocken i grupperna **Text**, **Media**, **Interaktivt**, **Callouts**, **Dynamiskt innehåll**, **UI-element** och **Tabeller**, i den ordningen. De flesta block finns också i [redigerarens verktygsfält](/platform/editor#verktygsfältet).

## Text

| Block | Vad det gör |
| --- | --- |
| **Stycke** | Vanlig brödtext. |
| **Rubrik 1** till **Rubrik 6** | Rubriker för olika avsnitt. |
| **Punktlista** | Lista med punkter. |
| **Numrerad lista** | Lista med nummer. |
| **Kodblock** | Kodexempel med syntaxmarkering. |

Formatering i löptexten (fet, kursiv, understruken, genomstruken, kod och länkar) finns i verktygsfältet och via de vanliga kortkommandona.

## Media

| Block | Vad det gör | Inställningar |
| --- | --- | --- |
| **Bild** | Ladda upp en bild (JPG, PNG, WebP eller GIF) eller skapa en med AI. | Dra i kanten för att ändra storlek. Eleverna får knappar för att förstora och ladda ner. |
| **Video** | Ladda upp en videofil (MP4 eller WebM). | Storlek: **Liten**, **Mellan**, **Stor**. Knappar för att förstora och ladda ner. |
| **YouTube** | Bädda in en YouTube-video. Öppnar blocket **Inbäddning** med YouTube förvalt. | Samma som **Inbäddning**. |
| **PDF** | Ladda upp en PDF och visa den i en inbyggd visare. | Dra för att ändra storlek. Knappar för att förstora och ladda ner. |
| **Ljud** | Ladda upp ljud, skapa inläst ljud med AI eller bädda in en podd. | Storlek: **Liten**, **Mellan**, **Stor**, **Full bredd**. Se nedan. |
| **Bibliotek** | Infoga en fil eller resurs från ditt [bibliotek](/platform/courses/library). | **Välj från biblioteket** eller **Ladda upp**, sedan **Visa som kort** eller **Visa i texten**. |

Du kan också klistra in eller släppa en fil direkt på sidan. Bilder (JPEG, PNG, WebP, GIF), videor (MP4, WebM) och PDF-filer laddas upp och blir motsvarande block.

### Ljudblocket

Ljudblocket har fyra flikar:

| Flik | Vad den gör |
| --- | --- |
| **Ladda upp** | Ladda upp en MP3-, WAV-, OGG- eller M4A-fil. |
| **Generera** | Skapa inläst ljud med AI: **Text till tal**, **Podd (2 röster)** eller **Tala**. Se [AI för lärare](/platform/ai/for-teachers). |
| **Avsnitt** | Bädda in ett avsnitt från någon av organisationens [poddar](/platform/podcasts). |
| **Spellista** | Bädda in en hel podd som spellista. |

## Interaktivt

| Block | Vad det gör |
| --- | --- |
| **Magiskt block** | Beskriv ett interaktivt element (en simulering, ett diagram, ett litet spel) så skapar AI det som HTML. Du kan förfina det upp till 6 gånger per block. |
| **Quiz** | Flervalsfrågor som eleverna svarar på direkt på sidan. Se [Quizblocket](#quizblocket). |
| **H5P** | Bädda in H5P-innehåll som ligger någon annanstans. Se [H5P](/platform/editor/h5p). |
| **Matematisk ekvation** | En LaTeX-ekvation, med väljarna **Mallar** och **Symboler** och en snabbreferens. |
| **Webbförhandsvisning** | Ett kort som förhandsvisar en webbsida. Se [Webbförhandsvisning](#webbförhandsvisning). |
| **Vändkort** | Ett kort med frågan på framsidan och svaret på baksidan. |
| **Vändkortsrutnät** | Flera vändkort bredvid varandra, i **2 kolumner**, **3 kolumner** eller **4 kolumner**. |
| **Kodlekplats** | En kodutmaning som kör riktig kod mot testfall. Se [Kodkörning](/platform/code-execution). |
| **Scenarier** | Ett förgrenat scenario: varje steg visar text (och eventuellt en bild) och några val som leder vidare till andra steg. **Generera med AI** skapar ett utkast åt dig. |

Block med AI-funktioner använder organisationens [AI-krediter](/platform/ai).

### Quizblocket

Varje fråga har en lista med svar, och du markerar ett eller flera av dem som rätt. En fråga med ett rätt svar visas som **Välj ett svar**. En fråga med flera rätta svar visas som **Välj alla som stämmer**. En fråga utan något rätt svar hoppas över.

Klicka på **Generera med AI** för att låta AI skriva frågor utifrån sidans innehåll. Du väljer mellan frågor med ett svar och frågor med flera rätta svar, förhandsgranskar resultatet och kan generera om innan du infogar frågorna.

Eleverna väljer sina svar och klickar på **Skicka** för att se om allt blev rätt, och sedan på **Återställ svar** för att försöka igen. Svar i quizblock bedöms inte och sparas inte. Vill du ha ett quiz som bedöms använder du en [uppgift](/platform/assignments) med en deluppgift av typen Quiz.

### Vändkort och vändkortsrutnät

Ett vändkort har en fråga, ett svar, en färg (10 att välja bland), en justering (vänster, mitten eller höger) och en storlek (liten, mellan eller stor). Eleverna klickar på kortet för att vända det.

Vill du lägga korten på rad infogar du ett **Vändkortsrutnät**, eller markerar ett befintligt vändkort och väljer **Gruppera i rutnät**. I ett rutnät lägger du till fler kort med **Lägg till kort** och gör om dem till enskilda kort igen med **Avgruppera kort**.

### Webbförhandsvisning

Ange en **Webbplats-URL** så visar blocket sidans titel, beskrivning och bild. Du kan slå på **Visa knapp**, ange en **Knapptext** och välja **Öppna popup i appen (fungerar kanske inte på alla webbplatser)** för att öppna länken i en popup i stället för i en ny flik. Du kan också ställa in kortets justering.

## Callouts

| Block | Vad det gör |
| --- | --- |
| **Callout** | En markerad ruta. Välj typ: **Info**, **Varning**, **Tips**, **Lyckades** eller **Fel**. |

## Dynamiskt innehåll

| Block | Vad det gör |
| --- | --- |
| **Variabel** | Ett värde som varje elev ser som sitt eget, till exempel sitt förnamn eller sina framsteg. |
| **Villkorligt innehåll**, **Visa för en grupp**, **Lås upp senare**, **A/B-test** | Block som bara vissa elever ser. |
| **Infoga mall**, **Spara som mall** | Återanvänd sparade block och sidor. |

Se [Dynamiskt innehåll och mallar](/platform/editor/dynamic-content).

## UI-element

| Block | Vad det gör |
| --- | --- |
| **Avgränsare** | En vågrät linje mellan avsnitt. Du kan också skriva `---` för att infoga en. |
| **Märke** | En färgad etikett med valfri emoji. |
| **Knapp** | En klickbar knapp som öppnar en länk. Du anger länk, färg och justering. |
| **Användare** | Ett kort som visar en användare i din organisation. Ange användarnamnet och klicka på **Ladda användare**. |
| **Inbäddning** | Bädda in externt innehåll. Se [Inbäddning](#inbäddning). |

### Inbäddning

Blocket **Inbäddning** tar antingen en URL eller en hel inbäddningskod (en `<iframe>` eller ett inbäddningsskript). Det har genvägar för YouTube, GitHub, Replit, Spotify, Loom, Google Maps, CodePen, Canva, Notion, Google Docs, X, Figma och Giphy, var och en med en länk till tjänstens egen instruktion för inbäddning. Du kan också klistra in valfri inbäddnings-URL direkt.

## Tabeller

| Block | Vad det gör |
| --- | --- |
| **Tabell** | Infogar en tabell med 3 × 3 celler och en rubrikrad. Använd verktygsfältet för att lägga till en rad nedanför, lägga till en kolumn till höger eller radera aktuell rad eller kolumn. Du kan ändra kolumnernas bredd. |

## Flytta block

Håll muspekaren över ett block och ta tag i handtaget till vänster om det för att dra blocket till en annan plats på sidan.
