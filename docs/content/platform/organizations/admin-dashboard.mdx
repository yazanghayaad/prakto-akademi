# Superadminpanelen

Superadminpanelen på `/admin` är till för dig som driver Prakto Akademi. Den ger en överblick över hela plattformen. Organisationens vanliga adminpanel på `/dash` används i stället för att hantera själva organisationen.

## Vem kan använda den

Bara **superadmins** kan öppna superadminpanelen. Det finns ingen skärm för att göra andra användare till superadmins.

Logga in på `/admin/login` med din e-postadress och ditt lösenord. Alla andra som loggar in ser **Åtkomst nekad**.

I toppmenyn hittar du bland annat **Organisationer**, **Användare** och **Statistik**.

## Organisationer

Listan visar varje organisation med webbadress, antal användare, kurser och admins samt datum. Du kan söka på namn och sortera listan, till exempel på nyast, äldst, flest användare, flest kurser, flest besök eller mest engagerade.

### Organisationens detaljer

Öppna en organisation för att se de här flikarna:

| Flik | Vad du kan göra |
| --- | --- |
| **Översikt** | Se antal användare, kurser och admins, organisationens uppgifter, adminanvändare och användning |
| **Kurser** | Se alla kurser med status och synlighet |
| **Användare** | Se alla medlemmar med e-postadress, roll och datum för när de gick med |
| **Statistik** | Se organisationens statistik för en period som du väljer |
| **Funktioner** | Slå på eller av funktioner för organisationen: AI, Statistik, Tavlor, Samarbete, Mappar, Communities, Medlemmar (och registreringsläget), Lekplatser och Poddar |
| **Inställningar** | Redigera organisationens namn, kortnamn (slug), e-postadress och beskrivning |

Det finns också en länk som öppnar organisationens egen adminpanel.

## Användare

En lista, som bara går att läsa, över alla konton på plattformen, med e-postadress, organisation, roll (**Superadmin** eller **Vanlig**) och datum. Du kan filtrera på roll och sortera listan på nyast eller äldst.

## Statistik

**Global statistik** visar hur plattformen har använts de senaste 30 dagarna.

<Callout type="warning">
Superadminpanelen kan inte radera organisationer eller användare. Radera en organisation från dess egen adminpanel under **Organisation** → **Farozon**.
</Callout>
