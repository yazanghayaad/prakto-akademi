# Kursinställningar

Öppna en kurs från **Kurser** i adminpanelen. Inställningarna är uppdelade i flikar. Du ser bara de flikar som din roll ger dig tillgång till:

| Flik | Vad den innehåller |
| --- | --- |
| **Allmänt** | Namn, beskrivning, lärandemål, taggar och miniatyrbild. |
| **Innehåll** | Kapitel och aktiviteter. Se [Kapitel och aktiviteter](/platform/courses/chapters-and-activities). |
| **Schema** | Släpp kapitel över tid. Se [Stegvis innehåll](/platform/courses/drip-content). |
| **Åtkomst** | Vem som kan se kursen. |
| **Medarbetare** | Vem som kan redigera kursen. |
| **SEO** | Hur kursen visas i sökmotorer och i sociala medier. Se [SEO](#seo) nedan. |
| **Certifiering** | Certifikatet som eleverna får. Se [Certifikat](/platform/certifications). |
| **Statistik** | Statistik för kursen. Se [Kursstatistik](/platform/analytics/course-analytics). |

## Allmänt

| Fält | Att tänka på |
| --- | --- |
| **Namn** | Högst 100 tecken. |
| **Beskrivning** | Högst 1000 tecken. |
| **Om** | En längre presentation som visas på kurssidan. |
| **Lärandemål** | Vad eleverna får ut av kursen. Minst ett krävs. |
| **Taggar** | Nyckelord för kursen. |
| **Miniatyrbildstyp** | **Bild**, **Video** eller **Båda**. |
| **Miniatyrbild** | **Ladda upp bild** (PNG eller JPG, högst 8 MB), **Ladda upp video** (MP4 eller WebM, högst 100 MB) eller skapa en med AI. |

## Åtkomst

Välj ett av två lägen:

- **Offentlig**: alla på internet kan se kursen, och sökmotorer kan indexera den.
- **Endast användare**: bara inloggade användare kan se den.

Under **Användargrupper** klickar du på **Länka till en användargrupp** för att bara ge medlemmarna i vissa användargrupper åtkomst. Användare utanför de länkade grupperna förlorar åtkomsten. Använd **Ta bort länk** för att ta bort en grupp.

Vill du styra mer i detalj har varje kapitel och aktivitet ett eget lås. Se [Lås kapitel och aktiviteter](/platform/courses/chapters-and-activities#lås-kapitel-och-aktiviteter).

## Medarbetare

Medarbetare är användare som kan arbeta med kursen tillsammans med dig. Var och en har en roll och en status (**AKTIV**, **INAKTIV** eller **VÄNTANDE**). Bara medarbetare med status **AKTIV** får åtkomst.

| Roll | Kan redigera kursen | Kan hantera medarbetare |
| --- | --- | --- |
| **SKAPARE** | Ja | Ja. Skaparens roll och status kan inte ändras. |
| **REDAKTÖR** | Ja | Ja |
| **BIDRAGSGIVARE** | Ja | Nej |
| **RAPPORTÖR** | Nej | Nej |

För att lägga till medarbetare söker du efter användare på namn eller användarnamn, markerar dem och klickar på **Lägg till valda**. Sedan kan du ändra en medarbetares roll och status eller ta bort personen.

<img src="/docs/img/pages/courses/course-contributors.webp" alt="Fliken Medarbetare med valen Öppen för bidragsgivare och Stängd för bidragsgivare, sökfältet för användare och kursens skapare med rollen SKAPARE och status AKTIV" width={1600} height={900} style={{ borderRadius: 10 }} />

Ställ in kursen på **Öppen för bidragsgivare** om du vill att användare ska kunna ansöka från kurssidan med **Ansök om att bidra**. Den som ansöker läggs till som **BIDRAGSGIVARE** med status **VÄNTANDE** tills en skapare, redaktör eller admin godkänner ansökan. **Stängd för bidragsgivare** stoppar nya ansökningar. De som redan är medarbetare behåller sin åtkomst.

## SEO

Fliken **SEO** i kursen ersätter organisationens standardinställningar för SEO för just den här kursen. Inställningarna för hela organisationen (webbplatskarta, robots.txt och standardtaggar) beskrivs i [SEO](/platform/organizations/seo).

Fliken har fyra delar:

| Del | Fält |
| --- | --- |
| **Grundläggande SEO** | **SEO-titel** (högst 70 tecken), **Metabeskrivning** (högst 160), **Nyckelord**, **Kanonisk URL**. Tomma fält ersätts med kursens namn och beskrivning. |
| **Open Graph** | **OG-titel**, **OG-beskrivning** (högst 200), **OG-bild-URL**. Kursens miniatyrbild används om ingen bild är angiven. |
| **Twitter-kort** | **Korttyp** (**Sammanfattning** eller **Sammanfattning med stor bild**), **Twitter-titel**, **Twitter-beskrivning** (högst 200). |
| **Robots och strukturerad data** | **Förhindra indexering av sökmotorer (noindex)**, **Förhindra att länkar följs (nofollow)**, **Aktivera JSON-LD-strukturerad data**. |

## Kursuppdateringar

På kurssidan kan de som redigerar kursen publicera uppdateringar (en rubrik och en text) med **Ny uppdatering**. Eleverna ser dem under **Kursuppdateringar**. Varje kurs har också ett RSS-flöde med sina uppdateringar på `/course/{course_id}/updates/feed`, där `{course_id}` är kursens UUID utan prefixet `course_`.
