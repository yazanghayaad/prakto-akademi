# Statistikpanelen

Öppna **Statistik** i adminpanelens sidomeny för att se siffror för hela organisationen. Sidan har två flikar, **Översikt** och **Avancerat**, och en tidsväljare med **7d**, **30d** och **90d** (30 dagar som standard). Perioden du väljer gäller för alla widgetar som visar en tidsperiod.

## Översikt

<img src="/docs/img/pages/analytics/analytics-overview.webp" alt="Fliken Översikt i statistikpanelen med Live nu, Registreringar, Kursregistreringar, Slutförda, Inlämningar och diagrammet Dagliga aktiva användare" width={1600} height={900} style={{ borderRadius: 10 }} />

### Nyckeltal

| Widget | Vad den visar |
| --- | --- |
| **Live nu** | Användare som har varit aktiva de senaste 5 minuterna. Klicka för att se varje användares aktuella sida, enhet, land och när de senast sågs. |
| **Registreringar** | Nya konton under vald period. Klicka för att se listan med e-post och registreringsmetod. |
| **Kursregistreringar** | Registreringar på kurser under perioden. |
| **Slutförda** | Slutförda kurser under perioden. |
| **Inlämningar** | Inlämnade uppgifter under perioden. |
| **Dagliga aktiva användare** | Unika användare per dag. |
| **Länder** / **Främsta länder** | Var besökarna kommer ifrån, när landet går att avgöra. |
| **Enheter** | Fördelningen mellan **Dator**, **Mobil** och **Surfplatta**. |
| **Främsta hänvisare** | Webbplatserna som skickar besökare till er. |

### Centrala widgetar

| Widget | Vad den visar |
| --- | --- |
| **Registreringstratt** | **Sidvisningar**, **Kursvisningar**, **Registreringar** och **Slutförda**, med konverteringsgrad för **Visning → Registrering**, **Registrering → Slutförd** och **Sida → Slutförd**. |
| **Främsta kurser** | Era mest visade kurser, med visningar, registreringar och slutföranden. |
| **Aktivitetsengagemang** | Lektionerna där eleverna lägger mest tid, med typ och genomsnittlig tid. |

## Avancerat

Fliken **Avancerat** har widgetar som går djupare.

<img src="/docs/img/pages/analytics/analytics-advanced.webp" alt="Fliken Avancerat med Organisationens tillväxttrend, Nya kontra återkommande användare, Kohortretention och Toppanvändningstimmar" width={1600} height={900} style={{ borderRadius: 10 }} />

| Widget | Beskrivning |
| --- | --- |
| **Organisationens tillväxttrend** | Nya konton, kursregistreringar och slutföranden per vecka |
| **Nya kontra återkommande användare** | Balansen mellan tillväxt och användare som kommer tillbaka |
| **Kohortretention** | Andel användare som fortfarande är aktiva efter registreringsveckan |
| **Toppanvändningstimmar** | Antal händelser per veckodag och timme |
| **Kursavhopp** | Var användarna slutar i varje kurs |
| **Tid till genomförande** | Mediantal dagar för att slutföra varje kurs |
| **Genomförandetakt** | Genomsnittligt antal dagar mellan slutförda aktiviteter |
| **Innehållstypens effektivitet** | Andel slutförda per aktivitetstyp |
| **Kurseffektivitetsmatris** | Antal aktiviteter jämfört med andel slutförda (storleken visar antal registreringar) |
| **Communitykorrelation** | Andel slutförda bland dem som deltar i diskussioner jämfört med dem som inte gör det |
| **Deltagarengagemangspoäng** | De mest engagerade eleverna, efter ett sammanvägt mått |
| **Ögonblicksbild av användarframsteg** | Antal användare i varje framstegsintervall per kurs |
| **Betygsfördelning** | Histogram över betyg på uppgifter |
| **Certifieringsgrad** | Andel av dem som slutfört en kurs som hämtar sitt certifikat |
| **Sökeffektivitet** | Vanligaste sökningarna och andelen sökningar utan träffar |

**Tid till genomförande** täcker alltid de senaste 180 dagarna, oavsett vad tidsväljaren visar.

## Exportera

Klicka på **Exportera** i sidhuvudet och välj **Ladda ner JSON** eller **Ladda ner CSV**. Filen innehåller datan bakom fliken du står på (Översikt eller Avancerat) för vald period, och får ett namn som `analytics_30d.csv`. För att exportera behöver du samma administratörsbehörighet som för att se widgetarna.

## Hur aktuell är datan

Resultaten sparas tillfälligt i upp till 1 minut på fliken Översikt och 5 minuter på fliken Avancerat. **Live nu** är alltid aktuell.
