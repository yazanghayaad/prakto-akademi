# Kursstatistik

Varje kurs har sin egen statistik. Öppna kursen i adminpanelen och gå till fliken **Statistik**. Där ser du hur eleverna hittar kursen, registrerar sig, tar sig igenom den och slutför den.

## Widgetar

Med väljaren **7d** / **30d** / **90d** högst upp väljer du tidsperiod (30 dagar som standard). Den översta raden visar **Visningar**, **Registreringar**, **Genomförda** och **Genomförandegrad** för kursen.

<img src="/docs/img/pages/analytics/course-analytics.webp" alt="Fliken Statistik i en kurs med Visningar, Registreringar, Genomförda och Genomförandegrad och trenddiagrammen nedanför" width={1600} height={900} style={{ borderRadius: 10 }} />

| Widget | Beskrivning |
| --- | --- |
| **Registreringstrend** | Nya registreringar per dag över tid |
| **Aktiva deltagare** | Unika aktiva elever i kursen per dag |
| **Kursbesökare** | Unika besökare på kurssidan per dag |
| **Visning → anslutning** | Hur många besökare som blir registrerade elever |
| **Slutföranden per dag** | Slutförda aktiviteter per dag |
| **Tratt för slutförda aktiviteter** | Visningar jämfört med slutföranden per aktivitet |
| **Tid per aktivitet** | Genomsnittlig tid som eleverna lägger på varje aktivitet |
| **Avhoppspunkter** | Var eleverna slutar komma vidare (senast slutförda aktivitet) |
| **Fördelning per aktivitetstyp** | Fördelning och andel slutförda per innehållstyp |
| **Engagemang per innehållstyp** | Mått på elevernas engagemang per aktivitetstyp |
| **Slutförandetakt** | Hur snabbt eleverna går från en aktivitet till nästa. Lägre är bättre. |
| **Tid till slutförande** | Hur lång tid det tar för eleverna att slutföra kursen |
| **Certifikatfrekvens** | Andel av dem som slutfört kursen som har hämtat sitt certifikat |
| **Daglig tid per deltagare** | Genomsnittlig tid som varje elev lägger per dag |
| **Deltagarnas framsteg** | Hur många aktiviteter eleverna har slutfört |
| **Mest aktiva studietimmar** | När eleverna är mest aktiva i kursen |
| **Deltagarretention** | Andel elever som kommer tillbaka efter första aktiviteten |
| **Främsta deltagare** | De mest aktiva eleverna, efter antal slutföranden |
| **Senaste anmälningar** | De elever som senast registrerade sig på kursen |

Klicka på expandera-ikonen på en widget för att öppna dess detaljvy. **Avhoppspunkter** listar till exempel varje aktivitet med antalet elever för vilka det är den sista aktiviteten de slutförde. Elever som har slutfört kursen räknas på kursens sista aktivitet, så den sista lektionen har oftast också en stapel.

<img src="/docs/img/pages/analytics/course-analytics-dropoff.webp" alt="Detaljvyn för Avhoppspunkter, med aktiviteterna listade efter hur många elever som senast slutförde dem" width={1600} height={900} style={{ borderRadius: 10 }} />

Med **Exportera** laddar du ner kursens data som JSON eller CSV.

## Vem kan öppna fliken

Fliken visas för användare som kan redigera kursen. Själva siffrorna visas dock bara för administratörer, så i praktiken behöver du en roll som får uppdatera organisationen (som standard rollen **Admin**).
