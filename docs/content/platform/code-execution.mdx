# Kodkörning

Prakto Akademi kör elevernas kod i en isolerad miljö. Du använder kodkörning på två ställen:

- Blocket **Kodlekplats**, en kodutmaning som du kan lägga till på vilken dynamisk sida som helst från `/`-menyn.
- Deluppgiftstypen **Kod** i [uppgifter](/platform/assignments/task-types#kod), för kodövningar som bedöms.

Båda kör kod på samma sätt. Den här sidan handlar om blocket Kodlekplats.

## Språk som stöds

Python 3, JavaScript (Node), TypeScript, Java, C++, C, Rust, Go, PHP, Ruby, Kotlin, C#, Swift, Scala, Perl, R, Dart, Haskell, Lua, Elixir, Clojure, SQL, Bash, Objective-C, Pascal, Fortran, Prolog, Common Lisp, PowerShell och Assembly (NASM). Det är 30 språk. Nya block börjar med Python 3.

## Skapa en utmaning

Infoga ett block av typen **Kodlekplats** och fyll i inställningarna:

| Inställning | Vad den gör |
| --- | --- |
| **Språk** | Språket som eleverna skriver i. |
| **Beskrivning** | Själva uppgiften. Du kan använda Markdown. |
| **Svårighetsgrad** | **Lätt**, **Medel** eller **Svår**. Visas som en etikett. |
| **Startkod** | Koden som eleverna utgår från. |
| **Testfall** | Varje testfall har ett namn, **Indata** (skickas till stdin) och **Förväntad utdata**. |
| **Ledtrådar** | En lista med ledtrådar som eleverna kan öppna en i taget. |
| **Lösningskod** | Din exempellösning. Visas för eleverna efter tillräckligt många försök. |
| **Försök för att låsa upp** | Hur många testkörningar en elev behöver göra innan lösningen låses upp. Standard är 3. |
| **Tidsgräns** | Längsta körtid per körning. Standard är 10 sekunder. |
| **Förväntad hastighet** / **Förväntat minne** | Den tids- och minneskomplexitet du förväntar dig. Visas för eleverna. |
| **Tidsutmaning** | Lägger till en nedräkningstimer. Ställ in **Längd (minuter)**. Standard är 5 minuter. |
| **Ytterligare filer** | Extra filer som elevens kod kan använda, till exempel `data.txt` eller `utils.py`. |

För **SQL**-utmaningar kan du också ladda upp en SQLite-databas (`.sqlite`, `.db` eller `.sqlite3`). Elevernas frågor körs mot den.

### Låsta rader och luckor

Två markeringar i startkoden ändrar vad eleverna kan redigera:

- Rader mellan två `// --- locked ---`-markeringar är skrivskyddade för eleverna.
- Rader mellan två `// --- blank ---`-markeringar blir luckor: eleverna fyller bara i den delen.

## Det här ser eleverna

Eleverna skriver kod i en redigerare med syntaxmarkering och automatisk komplettering, och kör den sedan.

- **Kör kod**: `Ctrl+Enter` (`Cmd+Enter` på macOS). Finns det testfall körs alla, och blocket visar vilka som gick igenom, utdata jämfört med förväntad utdata och en poäng.
- **Återställ kod**: `Ctrl+Shift+R` (`Cmd+Shift+R` på macOS) tar fram startkoden igen.
- **Dina testfall**: eleverna kan lägga till egna indata för att testa gränsfall.
- **Fel**: kompilerings- och körfel markeras på raden där de uppstår.
- **Visa lösning**: när antalet försök är uppnått kan eleverna öppna lösningen och jämföra den med sin egen kod sida vid sida.
- **Historik**: varje elevs körningar sparas, så att eleven kan gå tillbaka till ett tidigare försök. De senaste 500 per aktivitet sparas.

Resultaten i Kodlekplats är till för övning och bedöms inte. Vill du bedöma kod använder du en deluppgift av typen Kod i en uppgift.

## Begränsningar

| Begränsning | Värde |
| --- | --- |
| Testfall per körning | 50 |
| Enskilda körningar per elev | 60 per minut |
| Testkörningar med alla testfall per elev | 20 per minut |
| Källkodens storlek | 64 kB |
| Indata per testfall | 64 kB |
| Ytterligare filer | 20 filer, 128 kB per fil |

Kod kan bara köras av inloggade användare som har tillgång till aktiviteten.
