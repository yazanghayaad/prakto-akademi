# E-post

Prakto Akademi skickar e-post när något händer med ett konto eller ett medlemskap. Det finns inget aviseringscenter i appen, så allt nedan kommer som e-post.

## E-post om konto och medlemskap

| E-post | Skickas när |
| --- | --- |
| Kontot har skapats | Någon registrerar sig |
| Bekräfta e-postadressen | Ett nytt konto ska bekräfta sin adress, eller användaren ber om en ny länk |
| Magisk inloggningslänk | En medlem vill logga in med en [magisk länk](/platform/users/authentication) |
| Återställ lösenordet | En medlem klickar på **Glömt lösenordet?** |
| Inbjudan | En admin [bjuder in någon via e-post](/platform/users/members-and-invites#bjud-in-via-e-post) |
| Ny medlem i organisationen | Ett befintligt konto blir medlem i organisationen. Nya konton får i stället meddelandet om att kontot har skapats. |
| Rollen har ändrats | En admin byter roll för en medlem |
| E-postadressen har ändrats | Adressen på ett konto ändras. Meddelandet skickas till den tidigare adressen. |
| Organisationen har raderats | En organisation som du är admin för raderas |
| Kontot har raderats | Ett konto raderas |

De här meddelandena går inte att stänga av. De har din organisations utseende:

- **Avsändarnamn**: det **Avsändarnamn för e-post** som du anger i [organisationsinställningarna](/platform/organizations/settings#allmänt). Själva avsändaradressen är alltid plattformens egen. Lämnar du fältet tomt används standardnamnet.
- **Språk**: organisationens **Standardspråk**.
- **Logotyp och färg**: din kvadratiska logotyp (eller den breda om du inte har någon kvadratisk) och din primärfärg från **Varumärke**.
